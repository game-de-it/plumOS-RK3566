# RG353Mの輝度ショートカット

STARTを押したまま十字キーの左を押すと1段階暗くなり、右を押すと1段階明るくなる。1〜20の既存の輝度設定に保存する。

RG353Mの入力サービスがゲームパッドを監視し、既存のバックライト制御を呼ぶ。BubbleはSTART単独のメニュー操作をボタン解放時に確定し、輝度ショートカットに使った入力ではメニュー操作を実行しない。ゲームにはゲームパッド入力も配信される。

輝度設定の更新はBubbleおよび音量設定と共通のロックで直列化した。Dockerで模擬バックライトと設定ファイルを使い、上下1段階の反映、1と20での停止、既存の設定値と輝度項目がない設定ファイルの保持を確認した。

## RG353Mの実機確認

- Docker生成のSYSTEMをUSB ADBで更新した。SHA-256は `29e831e46bc48b88791aeeb6cfc2d0fecaa5079df4e00c015996084246f2029f`。
- BubbleではSTART＋右で6→7（バックライト値7→10）、START＋左で7→6。右単独では輝度が変わらず、START単独ではメニューが開いた。ショートカット操作でSTARTメニューが開くことはなかった。
- RetroArch gpSPのゲーム中にSTART＋左で6→5（同7→5）、START＋右で5→6→7。同じRetroArchのDRM所有者が動作を続けた。
- `boot-system keep` で既定に設定して再起動し、設定7とバックライト値10が復元された。
- USB給電中の `mem` SleepからRTCで復帰し、設定7とバックライト値10が維持された。復帰後のSTART＋左で試験前の設定6に戻し、BubbleとUSB ADBの動作を確認した。
