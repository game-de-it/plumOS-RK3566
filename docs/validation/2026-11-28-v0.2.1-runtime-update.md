出荷イメージに同梱された公開鍵で署名を照合した。Dockerでは公開済みイメージから取り出したSYSTEMを使い、利用者と同じ `PLUMOS/updates/` に配布用アーカイブを置き、フロントエンドの `START → System Settings → System Update` で選択した。適用と `runtime_healthy` を確認し、更新後の5ファイルをマニフェストのハッシュと照合した。Apps設定にPPSSPPが追加され、ランタイムの `VERSION` は `0.2.1` になった。再起動はDocker内で模擬した。
