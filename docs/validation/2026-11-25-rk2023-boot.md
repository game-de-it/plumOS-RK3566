# RK2023の初回起動

RG503で使用した共通の起動SDをRK2023へ移し、利用者が内蔵画面にBubbleが表示されることを確認した。SDの再書き込みは行っていない。

共通イメージには `rk3566-rk2023-linux.dtb` が入っている。同梱DTBの検査ではTF2は `mmc2` の `fe2c0000` で有効。内蔵パネルの規定は640×480。実機で選択されたDTB、DRMの画面モード、SD2の認識・マウントはシェル接続後に照合する。[同梱DTBの検査](2026-11-25-rg503-sd2.md) · [RK2023のハードウェア仕様](https://rocknix.org/devices/powkiddy/rk2023/#hardware)

MacでADBサーバーを再起動し、RK2023のNW SERVICESでADBをOFF→ONにした。ケーブルをRK2023のOTG端子へ移した後も、`adb devices -l` とmacOSのUSBツリーにplumOSのADBデバイスは現れなかった。使用中のケーブルではMacへの直結を試せなかったため、起動SDの利用者領域を使って実機の診断ログを回収する。

RK2023には内蔵Wi-Fiのある版とない版がある。今回の個体で無線デバイスが認識されているかは未確認。[Powkiddyの内蔵Wi-Fi版の告知](https://powkiddy.com/blogs/news/the-powkiddy-rk2023-pure-black-wifi-version-is-available-for-pre-order) · [RK2023のハードウェア仕様](https://rocknix.org/devices/powkiddy/rk2023/#hardware)
