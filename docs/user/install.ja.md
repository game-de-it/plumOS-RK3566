# システムカードの書き込みと初回起動

[English](install.md) · [ユーザーガイド](README.ja.md)

## カードの準備

[実機確認済みの機種](devices.ja.md)、TF1/SD1用のmicroSD（16 GB以上を推奨）、カードリーダー、ディスクイメージ書き込みツールを用意します。圧縮イメージとSHA-256チェックサムは同じリリースから入手してください。

書き込み先のカードは先にバックアップしてください。すでにplumOSを使っている場合は、パソコンで見えるFAT32のファイルに加え、セーブ、ステート、設定も保存します。カード全体をバックアップすれば、両方の領域を含められます。[データの保存先](storage.ja.md)

## 書き込みと起動

1. v0.2.0のリリースからイメージとチェックサムを入手し、圧縮ファイルを照合してから展開します。[v0.2.0リリース](https://github.com/game-de-it/plumOS-RK3566/releases/tag/v0.2.0)

   ```sh
   shasum -a 256 -c plumOS-RK3566-v0.2.0.img.gz.sha256
   gzip -dk plumOS-RK3566-v0.2.0.img.gz
   ```

   Linuxでは `sha256sum -c` でも照合できます。Windowsでは `Get-FileHash -Algorithm SHA256` で各ファイルの値を出し、チェックサムの該当行と比較します。

2. 展開した `.img` を選び、カードへディスクイメージとして書き込みます。書き込み先のデータは上書きされるので、実行前にドライブ名と容量を確認してください。ツールの検証が終わってからカードを取り出します。
3. 本体の電源を切り、機種に応じて **TF1**、**SD1**、**OS** と表記されたスロットにカードを挿します。システムカード単体で確認したい場合は、最初はTF2を空にして起動します。
4. 電源を入れ、ゲーム一覧が表示されるまで待ちます。初回はストレージを準備し、パソコンで読み書きできる **PLUMOS** というFAT32ボリュームを作ります。処理の途中で再起動する場合があります。カードを挿したまま完了まで待ってください。
5. カードを外す前にフロントエンドの **Shutdown** で電源を切ります。パソコンからゲームをコピーするときは **PLUMOS** を開きます。別のパーティションを初期化・フォーマットする案内が出た場合はキャンセルしてください。

## 任意のTF2/SD2

FAT32のカードを用意し、ルートに `Roms/` と必要に応じて `BIOS/` を作ります。抜き差しは電源を切った状態で行います。起動時にSD2にあるフォルダが使われ、セーブと設定はSD1に保存されます。[フォルダの例](storage.ja.md)
