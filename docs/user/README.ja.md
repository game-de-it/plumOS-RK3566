# plumOS-RK3566 ユーザーガイド

[English](README.md) · [ドキュメント索引](../README.ja.md)

対応機種、メニュー操作、ゲームの入れ方をここから確認できます。[SDカードの書き込みと初回起動](install.ja.md)

## 対応機種

共通SDイメージは起動時に本体を判定します。RGB30のr1とr2にも同じイメージを使います。

| 機種 | 実機での確認範囲 |
| --- | --- |
| Anbernic RG353M | 起動、フロントエンド、SD2、Wi-Fi、USB ADB、代表的なエミュレータ・音声・スリープ |
| Anbernic RG353V | 起動、SD2、USB ADB、USB接続中の電源投入、代表的なエミュレータ・Apps・音声・スリープ |
| Anbernic RG503 | 起動、960×544表示、SD2、別ケーブルでのUSB ADB、代表的なエミュレータ・Apps・音声・スリープ |
| Powkiddy RGB30 r1 / r2 | 両方で起動、基板の自動判定、フロントエンド、ADB。SD2・エミュレータ・音声の詳しい試験はr2で実施。 |
| Powkiddy RK2023 | 起動、640×480表示、SD2、USB ADB、代表的なエミュレータ・Apps、スリープ、USB DACから内蔵スピーカーへの切り替え。試験機ではWi-Fiハードウェアが検出されていない。 |

RG353PとRGB10 Max 3の機種定義は収録済みで、plumOSの実機起動は未確認です。RG353VSも実機未確認で、専用の機種定義は収録されていません。[機種ごとの検証記録](../boot-and-device-support.md)

## 操作と音声

| 場面 | 操作 |
| --- | --- |
| フロントエンド | 十字キーで移動、`A`で決定・起動、`B`で戻る、`START`でメインメニュー。 |
| フロントエンドでゲームを選択中 | `SELECT`で使用するエミュレータやコアを選択。 |
| RetroArch | **SELECT＋B**でクイックメニュー。どちらを先に押しても開きます。FN搭載機では**FN**でも開きます。 |
| PicoArch・単体エミュレータ | RG353M・RG353V・RG503では**FN**、RGB30・RK2023では**SELECT＋START**でメニュー。 |
| Ports・Pyxel | ゲームやアプリごとの操作と終了メニューを使用。 |
| 電源 | 電源ボタンの短押しで電源メニュー。スリープは `Sleep` を選び、電源ボタンの短押しで復帰。カードを外す前は `Shutdown`。 |
| 音量 | ゲーム中も本体の音量ボタンで調整可能。フロントエンドの `Volume` からも変更できます。 |

RetroArchの既定では `SELECT＋START` でフロントエンドへ戻り、`SELECT＋R` でステート保存、`SELECT＋L` で読み込みます。キー割り当てを変更している場合は、エミュレータのメニューから操作できます。

RG353Mでは `START` を押しながら十字キーの左右で輝度を調整できます。音量は小さい範囲ほど細かく変化します。対応するUSB DACをデータ通信できるOTG端子に挿すと、プレイ中も出力先を切り替えられます。抜去後にスピーカーへ戻ることは代表的な構成で確認済みです。動作はDACとゲームによって異なります。

表示言語は `START` → `System Settings` → `Language` で変更できます。

## ゲームとセーブ

ゲームROMと、必要な場合は対応するBIOSを用意してください。SD1の **PLUMOS** ボリュームまたはFAT32のSD2で、ルートの `Roms/<機種別フォルダ>/` にROMを、`BIOS/` にBIOSを置きます。SD2にROMまたはBIOS用フォルダがある場合は、対応するSD1側のフォルダより優先されます。ディスク作品の `.cue` や `.m3u` が参照するファイルは一緒に置きます。

| フォルダの例 | ファイルの例 |
| --- | --- |
| `Roms/nes/` | ファミコンの `.nes` |
| `Roms/sfc/` | スーパーファミコンの `.sfc`、`.smc` |
| `Roms/gb/`、`Roms/gba/` | ゲームボーイの `.gb`、ゲームボーイアドバンスの `.gba` |
| `Roms/nds/`、`Roms/psp/` | Nintendo DSの `.nds`、PSPの `.iso`、`.cso` |
| `Roms/psx/` | PlayStationの `.cue`、`.chd`、`.pbp`、`.m3u` |
| `Roms/openbor/`、`Roms/pyxel/` | OpenBORの `.pak`、Pyxelの `.pyxapp` |

ゲームを追加したら `START` → `UI Settings` → `Refresh TOP` で一覧を更新します。ジャケット画像はWi-Fi接続後に `START` → `Apps` → `Scraping` から取得できます。取得できるかはROMと配信元の画像によって異なり、取得した画像はSD1の `Images/` に保存されます。

セーブ、ステート、設定は、SD1の管理領域 `/storage/plumos-rk3566/frontend/` 以下に保存されます。RetroArchではその中の `saves/` と `states/` を使い、単体エミュレータやPortsは個別の保存先を使う場合があります。セーブを含めるにはカード全体をバックアップするか、SFTPやADBで保存先からコピーしてください。ステートを使い続ける場合は、作成時のエミュレータとコアも控えておいてください。

## ネットワークとUSB

Wi-Fiハードウェアが検出された機種では、`START` → `Network Settings` → `Connect Wi-Fi` でSSIDを選びます。同じメニューの `INFORMATION` でIPアドレスを確認し、`NW Service` で必要なサービスを有効にします。

| サービス | 接続方法 |
| --- | --- |
| SSH / SFTP | 本体のIPアドレス、ポート22。初期ログインは `root` / `plumos`。SFTPは利用者領域から開きます。 |
| FTP | 本体のIPアドレス、ポート21。匿名で利用者領域に接続できます。 |
| Samba | 共有名は `SDCARD`。初期ログインは `plumos` / `plumos`。共有は利用者領域を開きます。 |
| USB ADB | データ通信できる端子とケーブルでパソコンにつなぎ、`adb devices -l` で確認します。`NW Service` で切り替えられ、設定の反映に再起動が必要な場合があります。 |

初期ログイン情報はシリーズ共通で、USB ADBはrootシェルを提供します。使用するサービスを、信頼できるネットワークやパソコンで有効にしてください。

## 更新とトラブル対処

- **使っている版に対応する更新がある。** チェックサムを照合し、署名付きのRK3566用ランタイムパッケージをSD1の **PLUMOS** ボリュームの `updates/` に置きます。`START` → `System Settings` → `System Update` から選び、再起動まで案内に従います。この更新ではブートローダーとカーネルは変更されません。リリースがフルイメージで提供されている場合は、データを保存してから書き込み手順に従ってください。[インストール](install.ja.md)
- **フロントエンドが表示されない。** 初回のストレージ準備が完了するまで待ちます。起動が止まったままなら、イメージのチェックサムとTF1の挿入位置を確認し、電源を切ってTF2を外してから試します。報告時は機種名、イメージの版、画面に出たメッセージを控えてください。
- **SD2やゲームが見えない。** 電源を切ってFAT32のカードとルートのフォルダ構成を確認し、起動して一覧を更新します。TF2を空にして起動するとカード側の切り分けができます。カードが認識されていてファイルシステムエラーがある場合は、`Apps` の `Repair SD2` を使います。
- **USBが給電だけになっている。** データ通信できる端子とケーブルを確認し、パソコンの接続許可が出たら許可してから `adb devices -l` を確認します。RG503は別のデータケーブルでUSB ADBの接続と転送を確認できました。[RG503の再試験](../validation/2026-11-25-rg503-runtime.md#別ケーブルでのusb-adb再試験)
- **ゲームが遅い、音が出ない、または起動しない。** 選択中のコア、BIOSの要件、現在の音声出力先を確認します。性能と互換性はタイトルごとに異なります。エミュレータの試験表には代表タイトルの起動結果と未試験のプロファイルを記録しています。[実機検証の一覧](../developer/README.ja.md#実機検証)
