# トラブル対処

[English](troubleshooting.md) · [ガイドの目次](README.ja.md)

- **フロントエンドが表示されない。** 初回のストレージ準備が完了するまで待ちます。起動が止まったままなら、イメージのチェックサムとTF1の挿入位置を確認し、電源を切ってTF2を外してから試します。報告時は機種名、イメージの版、画面に出たメッセージを控えてください。
- **SD2やゲームが見えない。** 電源を切ってFAT32のカードとルートのフォルダ構成を確認し、起動して一覧を更新します。TF2を空にして起動するとカード側の切り分けができます。カードが認識されていてファイルシステムエラーがある場合は、`Apps` の `Repair SD2` を使います。
- **USBが給電だけになっている。** データ通信できる端子とケーブルを確認し、パソコンの接続許可が出たら許可してから `adb devices -l` を確認します。RG503は別のデータケーブルでUSB ADBの接続と転送を確認できました。[RG503の再試験](../validation/2026-11-25-rg503-runtime.md#別ケーブルでのusb-adb再試験)
- **ゲームが遅い、音が出ない、または起動しない。** 選択中のコア、BIOSの要件、現在の音声出力先を確認します。性能と互換性はタイトルごとに異なります。エミュレータの試験表には代表タイトルの起動結果と未試験のプロファイルを記録しています。[実機検証の一覧](../developer/validation.ja.md)
